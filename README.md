# 리빙 블로그 트렌드 플래너 (가칭)

리빙 블로거가 버튼 한 번으로 오늘 쓸 주제와 포스팅 브리프를 받을 수 있는 웹 서비스

**배포 주소**: https://aiffel-project5.vercel.app

## 사용 방법

1. **프로필 저장**: 블로그 분야·카테고리·글 톤·제목 스타일·관심 키워드를 한 번 입력해 저장합니다. 이 브라우저에 저장되어 새로고침해도 남아 있고, 언제든 "프로필 수정"으로 바꿀 수 있습니다.
2. **오늘 기획 시작**: 버튼을 누르면 추천 주제 3개가 유형(이벤트형·시즌형·구매가이드형), 추천 이유, 출처 링크와 함께 카드로 보입니다.
3. **주제 선택**: 카드 하나를 고르면 제목 후보 3개, 소제목 구성, 타깃 키워드가 담긴 포스팅 브리프가 보입니다.
4. **ChatGPT·Claude로 보내기**
   - **ChatGPT에서 열기**: 새 탭에서 ChatGPT가 열리고 지시문이 입력창에 채워집니다.
   - **Claude에서 열기 (붙여 넣기)**: 지시문을 복사한 뒤 새 탭에서 Claude를 엽니다. 입력창에 Ctrl+V로 붙여 넣으면 됩니다.
   - **브리프 복사**: 지시문을 복사해 다른 AI 도구에 직접 붙여 넣을 수 있습니다.

지시문 맨 위에는 프로필의 글 톤과 제목 스타일이 들어가서, 따로 설명하지 않아도 내 블로그 스타일로 글을 쓰게 합니다.

## 현재 범위

- 추천 주제는 **예시 데이터(목업)** 입니다. 화면에도 "현재는 예시 트렌드 데이터예요"라고 표시됩니다.
- 실제 트렌드 자동 수집(네이버 API 연결)은 결제수단 등록이 필요해 **다음 단계**로 미뤘습니다.
- 서버 없이 브라우저에서만 동작하는 정적 웹페이지이며, 프로필은 사용자 브라우저(localStorage)에만 저장됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면의 뼈대: 프로필 입력, 시작 버튼, 추천 카드, 브리프와 버튼, 안내 토스트 |
| `styles.css` | 화면 디자인: 색, 카드, 유형 태그, 버튼, 모바일 배치 |
| `mock-data.js` | 예시 데이터: 11월 추천 주제와 주제별 제목 후보·소제목·키워드 |
| `app.js` | 동작: 프로필 저장·불러오기, 화면 전환, 출처 없는 주제 제외, 지시문 만들기, 복사·ChatGPT·Claude 열기 |
| `PRD.md` | 기획 문서: 범위(Must/Won't)와 검증 기록 |
| `.gitignore` / `.vercelignore` | 비밀값 파일(`.env`)이 저장소·배포에 올라가지 않게 막는 설정 |

## 실행 방법

- 배포 주소로 접속하거나, 저장소를 내려받아 `index.html`을 브라우저로 열면 됩니다. 설치할 것은 없습니다.
